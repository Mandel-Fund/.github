## About Mandel Fund

Mandel Fund is a quantitative trading and financial technology organization dedicated to building high-performance, data-driven trading systems and risk management platforms. We combine deep expertise in software engineering, data science, and financial markets to develop automated strategies, robust analytics tools, and scalable trading infrastructure.

**Our Mission:** Engineer disciplined, systematic approaches to financial markets through rigorous quantitative research and modern software development practices.

## Key Projects

### 🚀 RM Trader
**Risk-Managed Automated Trading Platform**

A full-featured algorithmic trading system with integrated risk management controls. Designed for systematic strategy deployment across multiple asset classes with real-time portfolio monitoring and automated risk enforcement.

**Key capabilities:**
- Multi-strategy backtesting and live execution engine
- Real-time P&L tracking and risk limit enforcement
- Broker API integrations with automated order management
- Dashboard for strategy performance visualization and reporting
- Configurable position sizing and drawdown protection

```
RM Trader Architecture
├── Strategy Engine
│   ├── Signal generation & backtesting framework
│   ├── Live execution & order management
│   └── Multi-asset class support
├── Risk Management
│   ├── Real-time exposure monitoring
│   ├── Automated stop-loss & position limits
│   └── Portfolio-level drawdown controls
├── Data Infrastructure
│   ├── Market data ingestion pipelines
│   ├── Historical data storage & retrieval
│   └── Analytics and reporting layer
└── Frontend Dashboard
    ├── Performance attribution views
    ├── Live P&L and risk dashboards
    └── Strategy configuration interface
```
